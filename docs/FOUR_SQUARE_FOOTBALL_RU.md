# КВАДРАТ — футбол на асфальте · Roblox MVP

**Автор правил — Югатн.** Игра проектируется как самостоятельная мини-игра YUGATNEO MATRIX. Код хранится на GitHub; Roblox Experience **ещё не опубликована**.

## Поле

- Большой квадрат 80 × 80 studs из материала Asphalt разделён на четыре равных игровых квадрата 2 × 2. Первый, второй, третий и четвёртый игрок закреплены за своими квадратами.
- В центре красный квадрат 8 × 8 studs: если после твоего удара мяч приземлился на нём, **тебе** начисляется один пропущенный гол.
- Классический футбольный мяч стилизован белым шаром с тёмными вставками. Движение мяча рассчитано серверным аркадным алгоритмом: видны полёт, падение и следующие отскоки. В этой версии не используется недетерминированная физика мяча.

## Правила матча

1. Партия начинается, когда подключились четыре игрока. Первый игрок подаёт по диагонали противоположному (1 → 4, 2 → 3).
2. При подаче **нужны два отскока** в квадрате принимающего. Только после второго отскока он вправе отбить мяч ногой. Исключение — удар головой с лёта. Если пропустил третий отскок подачи, получает один пропущенный гол.
3. Во время обычного розыгрыша удар ногой допускается **после первого отскока** в собственном квадрате. Второй отскок без отбивания — один пропущенный гол.
4. Если игрок ударил ногой до разрешённого отскока, он получает один пропущенный гол. Для штрафа сервер проверяет реальную близость игрока к мячу и его право на приём (чтобы чужие действия не создавали произвольных штрафов).
5. Удар головой в воздухе разрешён без предварительного отскока. Если после удара головой гол засчитан противнику, тот получает **сразу пять пропущенных голов и выбывает**.
6. Попадание после удара в центральный красный квадрат — штраф бьющему на один гол, в том числе если мяч был направлен туда головой.
7. Набрав пять пропущенных, игрок выбывает. Последний действующий игрок побеждает. Если все четверо остаются подключёнными, следующая партия стартует автоматически.
8. Игрок отбивает мяч, находясь в своём квадрате, или за внешней границей, если мяч уже отскочил на его поле и игрок пытается его догнать. Из чужого квадрата ударить нельзя.
9. Если игрок по диагонали выбыл, следующий подающий выбирает другого активного соперника по кругу (дополнение для матчей после выбывания). Пропустивший обычно подаёт следующим, если остался в игре.

**Предположения, требующие окончательного согласования:** два отскока на подаче заменяют стандартное правило двух отскоков; третий засчитывает гол. Штраф за гол головой — пять пропущенных, а не пять бонусных очков стрелявшему. Эти положения легко изменить в едином серверном модуле правил.

## Управление

| На компьютере | На смартфоне | Назначение |
| --- | --- | --- |
| 1 / 2 / 3 / 4 | Кнопки №1–4 | Прицел в чужой квадрат |
| 0 | «Центр!» | Красный центральный квадрат; собственный штраф |
| F | «НОГОЙ» | Удар после разрешённого отскока |
| H | «ГОЛОВОЙ» | Удар по мячу в воздухе |
| P | «ПОДАЧА» | Первая подача по диагонали |
| V | «Сверху» | Переключение обзора |

Необходимо находиться рядом с мячом. Сервер проверяет расстояние, координаты аватара, состояние мяча, тип удара и право игрока выполнять действие. Кнопка не гарантирует автоматический удар из любой точки.

## Запуск на Mac

Нужны Roblox Studio, Rojo CLI и Rojo Studio plugin.

    git clone https://github.com/Yugatn/-YUGATNEO_Roblax.git
    cd -- -YUGATNEO_Roblax
    git switch feature/four-square-football-20261121
    python3 tools/validate_rojo_manifest.py square.project.json
    rojo build square.project.json -o four-square-football.rbxlx

Открой файл four-square-football.rbxlx как **отдельный** Place в Roblox Studio, затем запусти Test → Start Server → 4 Players.

В GitHub Actions настроена отдельная статическая проверка и Rojo-сборка. Сама по себе сборка **не подтверждает**, что все действия отработаны с четырьмя участниками, и **не публикует** Place в Roblox.

## Тесты

- [ ] 4 персонажа в четырёх квадратах, 5-й наблюдает.
- [ ] Подача идёт по диагонали; при 1 отскоке принимать ногой нельзя, при 2 — можно, при 3 — пропущенный гол.
- [ ] Удар головой с лёта допустим, успешный гол головой начисляет 5 пропущенных и выбывание.
- [ ] В обычном розыгрыше второй отскок засчитывает 1 пропущенный.
- [ ] Центр штрафует последнего бившего, а не случайного другого игрока.
- [ ] Нельзя ударить из чужого квадрата или издалека.
- [ ] При выбывании одного/двух участников игра может продолжаться с оставшимися; после последнего — победитель.
- [ ] Смартфон: интерфейс, кнопки, камера и читаемость в портретном/альбомном режимах.
- [ ] В Roblox Studio вручную выполнен файл tests/SquareRulesSmokeTest.server.lua в ServerScriptService без ошибок.
- [ ] Проверен журнал Output и отсутствие повторных начислений от одного отскока.

## Файлы

- square.project.json — отдельный Rojo-проект.
