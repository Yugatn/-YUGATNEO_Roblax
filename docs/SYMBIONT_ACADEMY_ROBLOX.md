# СИМБИОНТ — Академия сотрудничества (Roblox MVP)

**Состояние на 20 ноября 2026:** реализованы исходники нового самостоятельного Rojo Place. Это не опубликованная Roblox Experience; требуется отдельная проверка Roblox Studio и публикация владельцем.

Шахматный default.project.json не изменён. Незавершённые PR #10–12, #16–17 в этот Place не встроены; конфликтующие наработки не продублированы.

## Что входит

- Три программно создаваемые 3D-площади, центральное лобби, перемещение между зонами и возврат, ProximityPrompt на игровых объектах.
- **Вода для каждого:** осмотр насоса → очистка фильтра → ремонт школы, клиники и домов в любом порядке → открытие общего клапана.
- **Мост сотрудничества:** осмотр → план → две независимые опоры → испытание → открытие моста.
- **Совет города:** три источника (бюджет, жители и инженеры) → один из трёх равноправных мирных вариантов (встреча, обращение, независимая проверка). Никакой политической принадлежности не требуется.
- Прогресс общий на один сервер; каждый участник может выполнять следующий доступный шаг. Подсчитывается число помогавших без передачи их UserId в интерфейс.
- Русский интерфейс: переключение трёх эпизодов, статусы шагов, вопросы для рефлексии, сообщения об успехе, сворачивание панели. ProximityPrompt работает с клавиатурой и сенсорным управлением.
- Сервер проверяет живого персонажа, дистанцию и частоту взаимодействий, зависимости действий и повторное выполнение. Клиентский скрипт только отображает данные.
- Все сцены и таблички построены из стандартных частей Roblox. Сторонние лицензированные ассеты не используются.

**Ограничения:** нет DataStore, закрытых лобби, разделения команд, сброса сыгранного эпизода без нового сервера, звука, анимации, эффекта текущей воды и фактического соединения с главным Hub. Метки 6+/10+ носят рекомендательный характер, не проверяют возраст Roblox. Кооперация рассчитана на 1–4 участника, но серверный код пока не ограничивает размер общего лобби.

## Как запустить в Roblox Studio на Mac

1. Установи Roblox Studio, Rojo v7 CLI и плагин Rojo для Studio.
2. В терминале выполни следующие команды:

    git clone https://github.com/Yugatn/-YUGATNEO_Roblax.git

    cd -- -YUGATNEO_Roblax

    git switch feature/symbiont-academy-roblox-mvp-20261120

    python3 tools/validate_rojo_manifest.py academy.project.json

    rojo build academy.project.json -o symbiont-academy.rbxlx

3. Открой symbiont-academy.rbxlx через Roblox Studio как НОВЫЙ Place.
4. В Studio выбери Test → Start. Для двух участников: Test → Start Server → 2 Players.
5. Игрок появляется на площади; на площадках выбирает одну из трёх игр, нажимает E или экранную кнопку и выполняет шаги по порядку.
6. Для live-sync вместо сборки можно использовать команду rojo serve academy.project.json и подключить Studio через Rojo Plugin.

**Публикация:** после проверки в Studio создай отдельный Experience/Place через File → Publish to Roblox, выстави соответствующий возрастной рейтинг. Существующий GitHub workflow публикации относится к шахматному build.rbxlx и его идентификаторам — не использовать его для Академии.

## Приёмка

- [ ] Academy Rojo build проходит, Studio открывает новый Place.
- [ ] Все три зоны и обратные перемещения доступны на ПК и смартфоне.
- [ ] Вода: нельзя активировать клапан до ремонта всех трёх узлов.
- [ ] Мост: нельзя открыть маршрут до проверки обеих опор.
- [ ] Совет: до ознакомления с тремя источниками все три варианта недоступны; после выбора альтернативы корректно закрываются.
- [ ] Два игрока видят общий прогресс и не получают баллы дважды.
- [ ] Чужой клиент не может запускать удалённые задания с другого конца карты.
- [ ] Повторные активации и попытки слишком быстрого нажатия отклоняются.
- [ ] Портретный и альбомный режимы смартфона не препятствуют передвижению и запуску Prompt.
- [ ] Roblox Studio ServerScriptService может вручную выполнить tests/AcademyRulesSmokeTest.server.lua без ошибок.

GitHub Actions проверяет существование файлов, структуру манифеста и собирает Rojo проект. Это **не** доказательство успешного прохождения реальной игры в Studio.

## Границы содержания

«Общество как организм» — авторская философская метафора, а не установленный научный закон. Игроки учатся анализу взаимозависимостей, сотрудничеству, проверке источников, рассмотрению компромиссов и мирным способам решать вымышленные городские проблемы.

Не добавлены политическая агитация, современные спорные политические события и требование принять мировоззрение для победы. Для чувствительных социально-политических тем Roblox предусматривает отдельные возрастные требования и политику модерации.

**Отдельная взрослая программа:** репродуктивное здоровье, отказ от алкоголя и табака, родительское внимание и цифровые привычки остаются в веб-модуле 18+. Не переносить их в детскую Roblox Experience. Не утверждать, что любое использование смартфона при ребёнке обязательно вызывает зависимость.

Официальные документы: https://create.roblox.com/docs/production/promotion/content-ratings ; https://create.roblox.com/docs/scripting/security/client-server-boundary ; https://rojo.space/docs/v7/project-format/
