# Книжный фонд «Библиотеки Икс» — контент-план и права

Этот документ НЕ предоставляет прав на книги или переводы, а фиксирует редакционную очередь. В текущей Roblox-сборке книги из `LibraryCatalog.lua` — **оригинальные короткие истории для YUGATNEO**, а не автоматически скачанные произведения сторонних авторов.

## Стартовая коллекция — готовые интерактивные книги

| BookId | Название | Возраст | Тренируемые навыки |
|---|---|---|---|
| `island` | Остров трёх вопросов | 8+ | критическое чтение и наблюдение |
| `forest` | Сад памяти | 7+ | память, сверка наблюдений |
| `spiral` | Дорога по спирали | 9+ | взаимопомощь, причинно-следственное понимание |
| `lights` | Письма светлячков | 6+ | понимание чужой перспективы |

Каждая книга содержит нумерованные абзацы и вопросы, в которых игроку надо **совместить книгу, место в тексте и смысловой ответ**. Позже расширить до 10–20 абзацев/глав, а также полноценной библиотеки, но загружать по главам при необходимости.

## Оригинальные русскоязычные и мировые произведения для последующей проверки

**Кандидаты:** басни И. А. Крылова, ранние рассказы и народные сказки в проверенных редакциях, произведения Л. Н. Толстого для детей, Х. К. Андерсена (оригинал и отдельная проверка перевода), «Алиса в Стране чудес» Л. Кэрролла (оригинал и отдельная проверка перевода), некоторые рассказы О. Генри, Жюля Верна. Не следует автоматически добавлять «Незнайку» Н. Носова, «Приключения на мыльном пузыре» без точного установления автора/редакции и правового статуса.

**Проверка до публикации:** имя автора и годы жизни, год произведения, точная редакция, территория распространения, автор перевода/годы жизни, права на иллюстрации/обложку, лицензия электронного файла, способ атрибуции и допустимость изменения текста. Пользоваться электронными библиотеками как инструментом поиска, а не презюмировать свободу любых текстов.

Проект Gutenberg поясняет, что их оценка отсутствия американских ограничений не обязательно относится к другим странам, а материалы с авторским разрешением на публикацию не всегда разрешено перепубликовывать третьим лицам: https://www.gutenberg.org/policy/license

## Поля карточки произведения

```lua
{
 id = "alice-original-english",
 title = "Alice's Adventures in Wonderland",
 author = "Lewis Carroll",
 language = "en",
 translation = nil, -- optional attribution / license per translation
 recommendedAge = "9+",
 editorReview = "PENDING",
 rightsTerritories = {"US"}, -- list only if actually verified
 rightsEvidence = "link to legal source and dated review",
 chapters = {
   {id = "01", title = "Chapter One", paragraphs = {}}
 },
 questions = {
   {chapter = "01", paragraphId = 3, prompt = "...", answerId = 2}
 }
}
```

Без `editorReview="APPROVED"` контент не включать в игровой манифест. Вначале проверить английский оригинал; русский перевод требует самостоятельной проверки. Изображение обложки — также отдельная лицензия.

## Внутриигровое оформление

- Полка «Сказки и выдуманные миры»: дружба, сотрудничество, творческое воображение.
- Полка «Учимся наблюдать»: внимание, сравнение источников, ошибка первого впечатления.
- Полка «История и культура»: факты, даты, музейные экспонаты, картография.
- Полка «Загадки и наука»: эксперименты, логические задачи, математические головоломки.
- Полка «Поэзия и ритм»: стихи с возможностью самостоятельного чтения; не копировать защищённые тексты.

## Педагогические требования

Короткие карточки для младших детей, настраиваемая длина главы, понятная навигация, чтение без таймера, приватные заметки, право выйти. «Быстрое чтение» не подменяет понимание: вопросы не сводятся к запоминанию случайной строки, а требуют ответить на смысл текста и показать опорный фрагмент. Оценка — результатов **игры**, не интеллекта человека как личности. Не ставить публичных диагнозов.
