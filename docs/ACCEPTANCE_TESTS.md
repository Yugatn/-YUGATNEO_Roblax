# Программа проверки качества YUGATNEO MATRIX (Acceptance Tests)

**Статус на дату создания:** написаны автоматические проверки доменных моделей и сценарии ручного тестирования. НИ ОДИН тест Roblox Studio в этой среде не выполнялся и не должен считаться пройденным. `rojo build` и GitHub CI также не заменяют проверку UI, физики и сети.

## 1. Базовая загрузка

| ID | Шаг | Ожидаемый результат |
|---|---|---|
| BUILD-01 | Собрать проект через Rojo | Файл `.rbxlx` без отсутствующих $path |
| STUDIO-01 | Запустить один клиент | Spawn, порталы, книга, тир и шахматы существуют |
| STUDIO-02 | Запустить 4–6 клиентов | Каждый получает собственный UI, без общих клиентских состояний |
| STUDIO-03 | Осмотреть Output | Нет ошибок загрузки модулей и RemoteEvent |
| STUDIO-04 | На телефоне | Панели книги, шахмат и магазина не блокируют друг друга |
| STUDIO-05 | Обход спирали пешком | Ни одной дыры в дорожном полотне или несогласованного уклона |
| STUDIO-06 | Два автомобиля | Машины не пропадают, можно управлять, тормозить и восстанавливать |
| STUDIO-07 | Умереть/перезапустить персонажа | Не зависают камера, промпты или активная сессия |

## 2. Библиотека

1. Подойти к четырём книжным стойкам. Название должно совпадать с текстом каталога; каждая открывает именно свою книгу.
2. Прочитать все четыре абзаца. Прокрутка и переносы строк работают на iPhone, Android и ПК.
3. Нажать «START READING RACE», указать правильный номер абзаца, затем правильный смысловой ответ. Сервер засчитывает время, первая победа даёт 20 внутриигровых монет.
4. Перепройти тот же текст. Рекорд обновится при улучшении, но повторная награда не выдаётся.
5. Указать неверный ответ: не выдавать монеты, не раскрывать секрет через RemoteEvent.
6. Отправить произвольный номер книги, длину заметки >350 символов, неположительное число, нелегальную команду: сервер отвергает.
7. Сохранить заметку и перезайти — прочитать сохранённый текст. При недоступном TextService сохранение отклоняется, ничего не публикуется.
8. Проверить, что чужой пользователь не видит личные заметки.
9. При недоступном DataStore UI должен оставаться работоспособным хотя бы в текущей сессии, но сообщение не должно утверждать, что данные сохранились навсегда.
10. Проверить таблицу рекордов в библиотеке на нескольких клиентах; время считается на сервере.

## 3. Интеллектуальные мини-игры

- **MEM-01:** показать 4–8 символов, затем скрыть их; неверный порядок не засчитывать.
- **MEM-02:** отправить ответ раньше истечения фазы запоминания; сервер отвергает.
- **ATT-01:** ровно один символ отличается от пятнадцати; индекс находится в диапазоне 1–16.
- **LOG-01:** последовательность имеет однозначное продолжение из четырёх вариантов.
- **SWI-01:** переключение «выбери цвет/выбери фигуру» не зависит от другого признака.
- **SPA-01:** расстояние по сетке соответствует сумме модулей разностей координат.
- **SYS-01:** при проверке любого ответа нет клиентского способа запросить приз произвольной величины.
- **SYS-02:** пять успешных заданий дают по одному одноразовому достижению и монетам, а не бесконечную награду за перезаход.
- **SYS-03:** выйти через крестик, снова зайти и пройти задание — предыдущая сессия не влияет на следующую.

## 4. Тир и ретро-аркада

- **TIR-01:** 45 секунд, движущиеся голографические утки, подсчёт попаданий сервером.
- **TIR-02:** выстрел за границами тира, непрерывный спам, клики на других игроков не начисляют очков.
- **TIR-03:** урон `Humanoid` равен нулю; ни у каких режимов нет оружия против детей.
- **RETRO-01:** Snake стартует из центра; нельзя развернуться на 180° и въехать в собственную шею.
- **RETRO-02:** Snake ест пиксель, увеличивает длину и score, завершает игру при ударе о стену/себя.
- **RETRO-03:** у 2 игроков Friendly Duel различаются роли P1/P2; удар с большого расстояния не уменьшает HP.
- **RETRO-04:** блок уменьшает урон, таймаут корректно определяет победителя либо ничью.
- **RETRO-05:** добровольный выход из ретроэкрана возвращает управление персонажем.
- **RETRO-06:** чужой клиент не может делать ход от имени другого и не может объявить себя победителем.

## 5. Детские игры

- **PLAY-01:** две персоны запускают догонялки, три — прятки; с меньшим числом игроков ожидание, но не фиктивный матч.
- **PLAY-02:** догонялки: после касания водящий меняется, нельзя мгновенно касаться повторно.
- **PLAY-03:** в прятках искатель не может двигаться в фазе укрытия и может после неё.
- **PLAY-04:** прикосновение через стену не считается.
- **PLAY-05:** любой игрок может нажать LEAVE; это размораживает его персонажа.
- **PLAY-06:** выход ведущего/искателя завершает игру без зависания.
- **PLAY-07:** отсутствие медицинских/шоковых эффектов, безопасное возвращение к Spawn.

## 6. Магазин и сохранения

- **SHOP-01:** невозможно купить предмет при нехватке монет.
- **SHOP-02:** нельзя получить предмет, отправив клиентом несуществующий ID.
- **SHOP-03:** очки, нимб и корона появляются только после покупки/экипировки; предметы не сохраняются в Roblox Avatar Shop.
- **SHOP-04:** при выборе VioletKart личный автомобиль меняет цвет, но не скорость.
- **SHOP-05:** покупка, перезаход, спавн и повторная экипировка сохраняют визуальное состояние.
- **SHOP-06:** два сервера одновременно пытаются изменить один профиль: нужны конфликтные тесты и последующая защита от двойной траты перед релизом.
- **SHOP-07:** нельзя начислить монеты произвольным RemoteEvent; их создаёт только проверенная серверная игровая логика.

## 7. Автоматические проверки в Studio

1. Временно поместить `tests/ArcadeRetroSmokeTest.lua` как Script под `ServerScriptService`; он импортирует `ArcadeLibrary`, `RetroEngine`, `BookCatalog`.
2. Временно поместить `tests/ChessEngineSmokeTest.lua`; проверить стартовый perft 20/400/8902, условия шаха и ничьей.
3. Дождаться сообщений `[YUGATNEO TEST] PASS...` и отсутствия ошибок; скопировать результаты в PR с точной датой/версией.
4. Удалить временные тестовые скрипты перед публичным релизом.

## 8. Критерий приёмки перед merge

- [ ] CI завершился успешной сборкой Rojo.
- [ ] В Roblox Studio с 4 клиентами проверены турниры и зрители.
- [ ] Проверены 5 интеллектуальных заданий, библиотека, заметки и 2 ретроигры.
- [ ] Проверены прятки/догонялки и выход из них.
- [ ] Проверены магазин, перезаход и отсутствие произвольного начисления валюты.
- [ ] На медленном мобильном устройстве проверены FPS и размер UI.
- [ ] Все ассеты проверены по лицензии и возрастному режиму.
- [ ] Тестировщик оформил протокол с датой, билдом, устройством и видео/скриншотами.

Если любой обязательный пункт не закрыт, оставлять PR в состоянии DRAFT, ничего не выдавать за готовый публичный релиз.
