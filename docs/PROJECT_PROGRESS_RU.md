## Вся мультивселенная: прогресс необходимо считать отдельно

Ранее в разговоре фигурировали приблизительные оценки ~65–70% исходников **первого MVP**. Это ориентировочные оценки разработки, не аудит полностью готового релиза. Для всего проекта потребуется единая матрица приёмки:

- Базовая матрица и спиральный маршрут: код, порталы, физика, доступность.
- Шахматы и турниры: правила, доски, очереди, зрители, многопользовательские проверки.
- Когнитивная аркада и тир: пять упражнений, безопасные цели, интерфейс.
- Библиотека: книги, конкурсы, заметки, награды.
- Оригинальные ретроигры и стратегии.
- Виртуальные питомцы и сохранение.
- Неоновые гонки, командная оборона, прятки и догонялки.
- Другие тематические измерения, транспорт и сюжет.
- Безопасность детской аудитории, система жалоб и доступность.
- Публикация, контроль производительности и реальные тесты Roblox Studio.

Не приписывать точные проценты всему миру без проверки масштаба каждой группы.

## Команды для инспекции

```bash
git fetch origin
git switch feature/story-x-defense-tactics-crafting
git pull
python3 tools/validate_storyx_project.py
rojo build -o build.rbxlx
rojo serve default.project.json
```

Открыть Roblox Studio и провести игровые испытания по `docs/DEFENSE_TACTICS_IMPLEMENTATION_RU.md`.

**Правило обновления:** после каждого этапа заносить конкретные завершённые критерии и приводить отдельно (а) процент исходников и (б) фактически выполненные тесты. Не повышать процент исключительно из-за написания документации.
