# STORY X / YUGATNEO MATRIX — интерактивная галерея романа

**Статус: код первой версии добавлен в GitHub. Реальные испытания Roblox Studio ещё не проведены.**
**Ветка:** `feature/story-x-interactive-gallery`.
**Автор художественной вселенной «Сюжет Икс»: Югатн.**

## 1. Художественная концепция

Игрок на 76-м сегменте спирального серпантина YUGATNEO MATRIX находит неоновую галерею. При входе он оказывается в отдельном выставочном зале, где можно гулять, рассматривать восемь оригинальных пиксельных композиций и читать короткие сценические адаптации линий романа. Это не учебник философии и не психологическая диагностика — это художественное пространство, предлагающее добровольное осмысление образов, выбор трактовки и исследование неизвестного.

В центре — **куратор**, открывающий каталог и список экспонатов. У каждой картины — отдельная стойка с `ProximityPrompt`. Она открывает текстовую страницу с краткой историей и вопросом по прочитанному. За правильный ответ эпизод отмечается как исследованный в рамках текущей игровой сессии; за ошибку нет наказания. Картину можно рассматривать без викторины.

Сцены основаны на основных сюжетных линиях авторского репозитория `Yugatn/story-x`, но **тексты выставки написаны специально для игрового формата; это не буквальные цитаты и не полные главы**.

## 2. Первые экспонаты и художественные задания

| ID | Название | Смысл | Пиксельный мотив | Дальнейшее развитие |
|---|---|---|---|---|
| `observer` | Наблюдатель | Югатн замечает повторения | глаз | следы на карте, наблюдательный квест |
| `mira` | Мира | другой субъект и самостоятельность личности | два силуэта | творческая мастерская, дневник Миры |
| `symbiont` | Симбионт | разговор с ИИ и пределы модели | сеть узлов | диалоги/задачи на гипотезы |
| `future` | Дневник 2300 | ретроспекция будущего ИИ | циферблат | временные загадки |
| `ambivalence` | Амбивалентный Солипсизм | «Я есть. Ты есть. Я не отрицаю Тебя» | два пересекающихся мира | философский зал |
| `catharsis` | Синема Катарсис | интерпретация увиденного | экран | музей кино, медиаграмотность |
| `spiral` | Спираль времени | последствия выбора | спираль | переходы между измерениями |

Не представлять изображения/сюжетные сцены как точное воспроизведение внешних фильмов. Для узнаваемой атмосферы использовать оригинальные иллюстрации автора, лицензированную музыку, собственные модели.

## 3. Геометрия и маршрут

Оригинальная **спираль** центрируется около `(500,0,0)`: радиус 120, 144 шага, три оборота, подъем 0,68 studs на сегмент. Галерея соединена короткой физической дорожкой с *шагом 76*. Входная платформа содержит стойку `GalleryEntrance` и ProximityPrompt.

**Выставочный зал:** центр `(3440,19,0)`, пол 146×116 studs, восемь панелей (по четыре вдоль каждой длинной стены), проходы, голографическая надпись, центральный куратор и четыре выхода: обратно на спираль, в основной Matrix, библиотеку и шахматный зал. Это отдельная дальняя зона одного Workspace; перенос в самостоятельный Roblox Place возможен при дальнейшем расширении.

Стойки экспонатов располагаются ближе к центральному проходу, чем картины, чтобы ребёнок мог взаимодействовать с интерфейсом, стоя на полу. Переходы происходят через сервер с доступной кнопкой Roblox, а не через недоступные элементы HUD.

**Пути вручную:** `Workspace.STORY_X_INTERACTIVE_GALLERY` создаётся скриптом `StoryXGalleryWorld.server.lua`. Если генератор не запустился, вручную собрать `GalleryFloor`, 8 `Artwork_<ID>`, `CuratorConsole`, `GalleryEntrance`, `Exit_Spiral`, `Exit_Matrix`, `Exit_Library`, `Exit_Chess` согласно координатам выше. Сохранять маршруты и не ставить стену перед входом, если геометрию переделывают.

## 4. Файлы и ручная установка

```text
src/server/
  StoryXGalleryCatalog.lua        ModuleScript: тексты/вопросы/пиксельные схемы
  StoryXGalleryAssets.lua         ModuleScript: белый список лицензированных AssetId
  StoryXGalleryWorld.server.lua   Script: помещение, стойки, переходы, проверка ответов
src/client/
  StoryXGallery.client.lua        LocalScript: интерфейс рассказов и викторин
tests/
  StoryXGallerySmokeTest.lua      временный Script, запускается в Studio
docs/
  STORY_X_GALLERY_IMPLEMENTATION_RU.md
default.project.json              Rojo mapping
```

Чтобы собрать вручную: открыть GitHub-файл → Raw → Copy. В Roblox Studio создать первые два **ModuleScript** и один **Script** в `ServerScriptService`, клиентский **LocalScript** в `StarterPlayer/StarterPlayerScripts`. Названия экземпляров обязаны точно совпадать с именами в конфигурации. В нормальном режиме лучше выбрать Git-ветку и выполнить `rojo serve default.project.json`, подключив плагин Rojo в Studio.

## 5. Добавление настоящих иллюстраций «Сюжета Икс»

На первом этапе восемь полотен создаются программно из заранее заданных 9×9 пиксельных узоров. Это **настоящие отображаемые 3D-экспонаты с SurfaceGui**, но они пока не равны более детальным артам из персональной библиотеки изображений автора.

**Чтобы заменить одно полотно художественным изображением:**

1. Выбрать оригинальный созданный автором или правомерно лицензированный файл; проверить оригинальность, согласие на распространение и возрастную приемлемость.
2. В Roblox Studio открыть **Asset Manager**, загрузить изображение от имени правильного владельца Experience и дождаться модерации/доступности.
3. Скопировать числовой `Image Asset ID` (не путь к локальному файлу или Library ID).
4. В `src/server/StoryXGalleryAssets.lua` изменить `id=0` на числовой ID, установить `license="ORIGINAL"` (или корректный `LICENSED`/`CC0`) и `approved=true` только после проверки прав и доступа изображения в Roblox.
5. Снова собрать игру. Сервер создаст `ImageLabel` в соответствующей `SurfaceGui` вместо пиксельного шаблона. Если ID запрещён/невалиден/не указан, отображается пиксельная композиция.
6. Для художественного QR-паспорта картины в дальнейшем добавить поля `title`, `artist`, `year`, `medium`, `license`, `rightsEvidence` и ссылку на связанную главу в архиве.

**Ни одна фотография, выложенная в чат или Library, автоматически не становится Roblox asset ID.** Без подтверждённой загрузки нельзя выдавать её за уже встроенную в игру. Текстовые главы также не встраивать целиком без редакционной/возрастной проверки.

## 6. Безопасность и содержательные ограничения

- Никакой свободной публикации заметок между детьми без фильтрации Roblox TextService. В первой версии **не предусмотрен общий чат от галереи**.
- Клиент видит текст и варианты ответа, но не получает скрытый индекс правильного ответа. Проверка `Catalog.verify` — только на сервере.
- Сервер разрешает отвечать лишь после взаимодействия с экспонатом и при нахождении в галерее в допустимый промежуток. Сообщения RemoteEvent ограничены по частоте.
- Система **не начисляет платные предметы или валюту** за викторину; это предотвращает повторное накопление жетонов переподключением. Счётчик посещений/разгадок существует пока только в памяти игрового сервера.
- Нет публичного ранжирования детей по «глубине понимания философии». Вопросы проверяют понимание описанного фрагмента, а не единственно правильное мировоззрение.
- Экспозиция не должна навязывать сложные/тревожные сцены младшим детям. Будущие материалы требуют редакционного разделения по возрасту.

## 7. Приёмка в Roblox Studio

| Сценарий | Ожидаемый результат |
|---|---|
| `rojo build -o build.rbxlx` | Все модули включены, компиляция структуры без отсутствующих файлов |
| Зайти на виток 76 | Физически доступная входная платформа и кнопка входа |
| Зайти в галерею | Появляется зал, пиксельные полотна, куратор, выходы |
| Нажать E на экспонате | Открывается соответствующая история и вопрос |
| Отправить неверный ответ | Нет успеха; повторная попытка разрешена |
| Отправить верный ответ | Отмечено как исследованное; нельзя прибавить счётчик второй раз |
| Прислать `Answer` из Матрицы/без выбора | Сервер отклоняет попытку |
| Два игрока одновременно | У каждого независимые посещения и результаты |
| Нажать `Exit_...` | Рабочий возврат, нет потерянного управления |
| Неподтверждённый `AssetId` | Пиксельный холст работает без изображения |
| На мобильном устройстве | Интерфейс прокручивается, кнопки читаются, закрытие работает |
| Повторно войти в сервер | Состояние викторины пока не сохраняется (ожидаемое ограничение MVP) |

**Дополнительное испытание:** скопировать `tests/StoryXGallerySmokeTest.lua` как временный Script в `ServerScriptService`; результат появится в Studio Output. Сам факт нахождения теста в GitHub не доказывает его выполнения.

## 8. Дальнейшая работа

**Порядок:** 1) собрать место и проверить прохождение; 2) загрузить настоящие восемь работ автора в Roblox Asset Manager; 3) сделать озвучивание коротких историй и субтитры; 4) добавить совместный музейный квест без обязательной соревновательности; 5) связать экспонаты с телепортами связанных измерений; 6) сохранить достижения и личную коллекцию работ с защищёнными серверными данными; 7) создать отдельный 3D-зал «Миры Сюжета Икс» для новых глав и персонажей.

Для расширения коллекции не менять игровой движок: добавить `entry` с уникальным `id` и авторским текстом в `StoryXGalleryCatalog.lua`; затем расширить планировку/таблицу картина → терминал, чтобы число экспонатов не стало причиной наложения мебели.
