# STORY X / YUGATNEO MATRIX — интерактивная галерея «Сюжета Икс»

**Версия:** 0.2 (исходный код), 23.10.2026. **Ветка:** `feature/story-x-spiral-gallery`. Код не является подтверждённой публикацией Roblox: нужны Studio, мобильные и многопользовательские испытания.

## Основная идея

Галерея — художественное измерение внутри общей игровой спирали, а не отдельный URL или текстовая справка. Ребёнок свободно заходит, рассматривает визуальные инсталляции, взаимодействует с экспонатами, узнаёт персонажей и идеи «Сюжета Икс», отвечает на необязательные вопросы, после чего возвращается к исследованию. Зал не оценивает интеллект или мировоззрение посетителя; награды не зависят от согласия с идеологией произведения.

Автор литературного мира: **Югатн**. Адаптация музейных карточек создана для игры. Исходные главы в репозитории [Yugatn/story-x](https://github.com/Yugatn/story-x), который остаётся самостоятельным источником литературного канона. Интерпретационные карточки в Roblox **не заменяют** оригинальный художественный текст и не заявляют, что являются дословными цитатами.

## Пространственная архитектура

**Спиральный вход:** step **58** по формуле `SpiralWorld.server.lua`, радиус 120 вокруг `(500,0,0)`, 144 шага/3 витка, высота шага +0.68. `StoryXGallery.server.lua` строит боковой мост и платформу, голограмму «ГАЛЕРЕЯ СЮЖЕТА ИКС» и ProximityPrompt. Игрок перемещается в зал.

**Основной зал:** центр `(900,20,420)`, 153 × 128 studs, стены и безопасный проход между экспозициями, центральная световая сфера «Наблюдатель». Десять картин расположены по противоположным сторонам зала, по пять на каждой. У каждой работы есть собственная информационная стойка, интерактивный текст и тематический арт.

**Выходы:** возвращение на виток спирали, в главный мир Матрицы, шахматный зал, библиотеку и когнитивную аркаду. Все переходы на сервере, с проверкой реальной дистанции до стойки; из активного шахматного/командного матча переход запрещён.

### Экспозиции (10)

| ID | Название | Связь с сюжетом | Игровое назначение |
|---|---|---|---|
| `observer` | Наблюдатель | Пролог и границы восприятия | различение события и интерпретации |
| `mira` | Мира — другой субъект | Мира наблюдает Югатна в ответ | признание автономии Другого |
| `trace` | След | повторяющиеся структуры и спирали | проверка гипотез |
| `symbiont` | Симбионт | диалоги человека и ИИ | ограничения моделей |
| `tv` | Телеэкран после перемен | революция и общественные обсуждения | критическое чтение новостей |
| `catharsis` | Cinema Catharsis | образ и чужой опыт | различение кадра и реальности |
| `future` | Дневник 2300 года | ИИ исследует историю XXI века | работа с архивными источниками |
| `matrix` | Пробуждение | переход между уровнями модели мира | философский вопрос |
| `other` | Другой | Амбивалентный солипсизм | признание Другого |
| `unknown` | Икс — неизвестное | незавершённый поиск | открытость новому знанию |

Каждая карточка включает `title`, `chapter`, `caption`, `story`, `question`, `options`, секретный на сервере `answer`, `imageAsset` и `route`. Правильный ответ не отправляется клиенту. Прогресс ответов — **атлас экспозиции**, не соревновательная психологическая оценка.

## Состояние изображений и импорт оригинальных иллюстраций

**В текущем коде нет импортированных иллюстраций с диска, из Library или из репозитория романа.** Реализованы десять оригинальных процедурных **пиксельных мозаик** на SurfaceGui. Это обеспечивает рабочую структуру зала без фальшивых или недоступных `rbxassetid`.

Для замены мозаик **на авторские иллюстрации**:

1. Подобрать изображение к конкретной главе. Для каждой работы проверить, что автор обладает правом публикации на Roblox; не выдавать чужие кинофрагменты и постеры за собственные.
2. В Roblox Studio / Creator Dashboard загрузить изображение как разрешённый для Experience asset. Зафиксировать **реальный** идентификатор изображения и убедиться, что asset прошёл модерацию Roblox и доступен в нужной Experience.
3. В `src/server/StoryXGalleryCatalog.lua` найти нужный `id` и заменить `imageAsset=0` на действительный числовой ID.
4. После обновления/синхронизации перезапустить тестовый сервер. Визуализация на SurfaceGui должна переключиться с процедурной мозаики на изображение через `ImageLabel.Image="rbxassetid://..."`.
5. Подтвердить на телефоне, что картина читаема, не мерцает и не содержит запрещённого контента. Если изображение не отображается, проверить модерацию, тип asset, права доступа и точность ID.
6. Сохранять исходные изображения за пределами Roblox в отдельной папке `gallery-source/` для специалистов, а в GitHub — только лицензированные файлы и их документированные источники.

**Предложения визуализаций:** Мира в двойном свете, Югатн и Симбионт за экраном неонового кода, дневник ИИ 2300-го года, телевидение после революции, спиральный след, Cinema Catharsis, инсталляция «Я есть. Ты есть», неизвестное Икс. Это идеи для авторской графики и будущих игровых диорам. Без явного подтверждения нельзя считать их уже созданными импортированными картинами.

## Игровая механика и сохранение

1. Игрок подходит к экспонату и нажимает E (либо сенсорный ProximityPrompt).
2. Сервер фиксирует посещение и отправляет карточку с визуальной идеей, историей и вопросом.
3. Клиент отображает прокручиваемую панель с выбором одного из трёх вариантов.
4. Сервер проверяет совпадение экспоната с реально открытым у игрока и расстояние до стойки, затем правильность ответа. За неверный ответ штрафа нет.
5. Прогресс `seen` / `solved` сохраняется через `DataStoreService:GetDataStore("YUGATNEO_STORY_X_GALLERY_V1")` с объединением флагов через `UpdateAsync`. При недоступном API Services данные могут работать только в текущей сессии.
6. Интерфейс показывает «исследовано X/10». **В этой версии нет денежной награды или маркетплейса за ответы.** При необходимости связать атлас с косметическими достижениями только после защиты от повторного начисления.

## Проверки для специалиста

- Пройти на шаг 58 по серпантину, убедиться, что мост стыкуется с дорогой и портал физически доступен.
- Проверить все 10 экспонатов, наличие их процедурного изображения и отдельного ProximityPrompt.
- Посмотреть, что панель текста открывается и закрывается, прокручивается на телефоне и не перекрывает игровые HUD после выхода.
- На двух игроках: ответы и прогресс одного не оказываются у другого; клиент не может удалённо отвечать, стоя в Матрице.
- Проверить правильный и неверный ответ; попробовать повторно начислить один и тот же экспонат.
- В тестовом Universe включить доступ к API Services, решить 2–3 вопроса, выйти и зайти снова. Должен восстановиться счёт «изучено».
- Умышленно отключить DataStore: сцена и задания остаются доступны, отсутствие долговременного сохранения явно обозначается.
- Пройти переходы галерея → библиотека, шахматы, аркада, Матрица, спираль; не допускать прерывания чужих матчей.
- Запустить временный тест `tests/StoryXGallerySmokeTest.lua` в ServerScriptService; ожидать PASS для десяти карточек и геометрии.
- Оценить клиентскую нагрузку на мобильных устройствах; статические мозаики не должны превращаться в бесконечные циклы или динамическую генерацию каждый кадр.

**Definition of Done:** успешный Rojo build, Roblox Studio Play без ошибок, 2 клиента без смешения прогресса, подтверждённая доступность всех десяти экспонатов, стабильный DataStore и проверенные авторские права на изображения. До выполнения критериев статус — IMPLEMENTED IN SOURCE, NOT RELEASED.


## Экскурсионный маршрут (версия 0.2)

Галерею можно исследовать свободно либо запустить **необязательную экскурсию**:

1. Войти через портал на витке 58.
2. Подойти к центральной сфере `ObserverCore` и выбрать `Начать экскурсию`.
3. Локальный HUD `GuidedTour` показывает номер работы из десяти, её название и подсвечивает следующую информационную стойку `Kiosk_<id>`. Подсветка создана **только на клиенте игрока** и не показывает местоположение других участников.
4. Подойти к экспонату и открыть его карточку. Маршрут переходит к следующему объекту **после просмотра**, а не после угадывания ответа.
5. В любое время нажать `ЗАВЕРШИТЬ ЭКСКУРСИЮ`. Никаких потерь очков, штрафов или задержек. Для возвращения к экскурсии снова использовать центральную сферу.
6. Если все экспонаты просмотрены, повторная экскурсия может начаться сначала. Для не завершивших просмотр маршрут при новом запуске начинается с первого ещё не открытого экспоната.

Порядок маршрута задаётся `Catalog.exhibits`, система не строит физические маршруты через PathfindingService. Текущая галерея компактная, экспонаты имеют таблички, но качество видимости на мобильном устройстве должно быть подтверждено вручную.

## Личный атлас экспозиции

Рядом с центральной зоной находится `StoryXAtlasTerminal`. Открывается `ProximityPrompt`. В атласе представлены названия всех десяти эпизодов, текущий статус каждого (`не открыто` / `просмотрено` / `изучено`) и его смысловая аннотация.

В атласе текст можно изучать без решения вопросов. Правильные ответы **не отправляются**. Для участия в викторине нужно подойти к соответствующей картине — это обеспечивает связь познания с исследованием реального 3D-пространства игры.

Для школьного/семейного режима экскурсия и атлас должны быть доступны без чата, соревновательного таймера и платных функций.

## Манифест визуальных файлов

Файл `docs/STORY_X_GALLERY_ART_MANIFEST.json` содержит десять ожидаемых `sourceFile`, `robloxImageAssetId=0` и статусы авторских прав/модерации. До загрузки авторских изображений поля остаются placeholders.

Порядок установки настоящих работ:

1. Подготовить иллюстрацию, приписанную правильной сцене, и документально подтвердить авторство/лицензию.
2. Сохранить графический оригинал в папке с именем из поля `sourceFile` (эта папка пока **не является частью GitHub-ветки**).
3. Загрузить изображение через Creator Dashboard, проверить модерацию и доступность для Experience.
4. Изменить `robloxImageAssetId` в манифесте **и** `imageAsset` в `StoryXGalleryCatalog.lua` на одинаковое реальное целое число. Установить `rightsStatus="APPROVED"`, `assetStatus="PUBLISHED_AND_MODERATED"`, заполнить `altText`.
5. Выполнить `python3 tools/validate_storyx_gallery_assets.py`. Скрипт останавливается при несовпадении, дублировании, отсутствии altText или неопределённом статусе прав на ненулевой ID.
6. Проверить визуализацию каждого экспоната в Roblox Studio и на телефоне. Автоматическая проверка инвентаря не гарантирует действительный доступ к опубликованному Asset ID.

Ни один найденный на внешнем сайте фильм, кадр игры или визуализация не считается разрешённым к использованию только потому, что находится в свободном доступе.

## Дополнительные тесты версии 0.2

- Центральная сфера запускает экскурсию, панель отображает первый ещё не посещённый экспонат.
- Правильное посещение переводит указатель на следующий; посещение другого экспоната не должно ломать маршрут.
- Завершение экскурсии удаляет только личную подсветку; у других игроков она не изменяется.
- Атлас отображает три статуса экспозиции и позволяет читать тексты без передачи ответов на сервер.
- Выход из галереи прекращает экскурсию; после возвращения атлас отражает сохранённые `seen/solved`.
- При отсутствии DataStore чтение и экскурсия остаются доступными; работа с профилем не должна обещать постоянное сохранение.
- Проверка прав/Asset ID проходит до Rojo build в GitHub Actions; тестовые изобразительные placeholder-ID 0 допустимы.
